# 外观设计规范：基于儿童审美研究（7-9 岁主力，覆盖 6-10）

设计 DNA 不变：**"一只睁着一只眼睛的蛋——像安静的小生物，绝不像数码产品。"**
本文用发展心理学与设计研究把它参数化：形态、颜色、配色、年龄适配，每条给出依据。

---

## 一、年龄段审美画像：7-9 岁 ≠ 幼儿园

这是整个规范的锚。购买者是妈妈（30-40），使用者是 7-9 岁小学生——两代人的审美研究结论**相反**，设计必须双面。

**7-9 岁的关键发展特征：**

1. **仍偏爱高饱和**：对 7-11 岁儿童的实证研究表明，在红/绿/蓝/紫各色相族中，**饱和度与偏好正相关**（Park, 2014, *Color Research & Application*）——孩子要鲜艳，粉彩淡色是成人审美。
2. **蓝色登顶、黄色退位**：约 7 岁起蓝色超过红色成为首选（社会化学习使红色与"停止/危险/错误"关联）；幼儿期最爱的黄/暖色随年龄下降——这是色彩发展文献的一致结论。
3. **性别分化已成型**：蓝、绿、粉、黑四色上男女差异显著；男孩 5-8 岁形成"避粉"，8-9 岁男孩偏蓝/绿/黑（"酷"），女孩从粉向紫/青转移。**单一配色必然流失一半用户，配色矩阵是研究结论不是营销花招。**
4. **"变老"倾向（KGOY, Kids Getting Older Younger）**：8-9 岁孩子在同伴面前**拒绝"幼齿"物品**——太像婴儿玩具的设备会被三年级学生藏进书包。他们要的是"可爱但有力量"（宝可梦/小马宝莉卡牌审美：萌 + 收集 + 战斗），不是"软萌奶油风"。
5. **手部人体工学（6-10 岁）**：手长约 12.5-15.5cm、手宽约 6-7cm → 机身宽 ≤70mm 才能单手环握；重量 ≤120g；实体键直径 ≥12mm（精细动作仍在发育）；必须耐 1.2m 跌落。
6. **低年级阅读**：一二年级识字者需要更大字号——2.8-3.5 寸屏上题目正文字符高度 ≥3.5mm（约屏幕上 16px+），行长短、行距松。

**设计裁决（双代审美的分工）**：
- **机身底色走中性暖白/暖灰**（妈妈的"高级感"，决定购买）；
- **高饱和留给三处**：发光眼环、可换外壳、屏幕里的宠物世界（孩子的"鲜艳"，决定喜爱）；
- **可爱度分层**：壳体克制（不幼齿，8-9 岁不嫌弃），屏内宠物拉满（婴儿图式最大化）。

## 二、形态规范（每条有依据）

1. **蛋形 + 全圆润轮廓 —— 曲率偏好**
   人类对圆润轮廓有系统性偏好，尖角激活杏仁核的威胁反应（Bar & Neta, 2006；Silvia & Barona, 2009；产品设计中圆角 > 直角的偏好被多次复现）。儿童场景下圆润同时满足安全（无尖角）与情感（温暖、无威胁）。
   → **全机身无一处尖角；最小圆角半径 8mm；侧面剖面为蛋形弧。**

2. **一只大眼 —— 婴儿图式（Kindchenschema）参数化**
   大眼睛、圆脸、高额头等婴儿图式特征跨年龄触发"可爱"知觉与照料动机（Lorenz 1943；Glocker et al., 2009, *Ethology*）；3-6 岁儿童已对高婴儿图式面孔表现注视偏好（Borgi et al., 2014, *Frontiers in Psychology*），该敏感性延续至学龄期。
   → **参数**：眼（镜头+光环）直径 = 正面宽度的 **32-38%**（婴儿图式的"大眼"区间）；眼位于正面**垂直中线偏上**（上 1/3 与中线之间——高额头暗示）；壳体在眼周有 0.5-1mm 的"眼睑"起伏。
   → **单眼的合法性**：独眼角色（小黄人、大眼仔）在儿童文化中被广泛接受且极具辨识度；单眼还回避了"双眼+嘴=婴儿脸"的过度幼齿化，正好平衡 KGOY。

3. **"活物感"由动态承担 —— 生命性知觉**
   儿童对自主运动/眼睛线索有很强的"生命体"归因（发展心理学的 animacy 研究传统；Tamagotchi 效应）。静态造型只是躯壳，**眼环的呼吸/眨眼/瞳孔亮灭**才是"它活着"的证据。
   → 眼环灯效状态机：睡（0.1Hz 缓呼吸）/ 醒（睁眼瞬亮）/ 火热（1Hz 脉动）/ 云游（熄灭）/ 拍照（常亮，硬件串联）。

4. **尺寸与重量（按"挂脖佩戴"重新收紧）**：**≈100×62×18mm、目标 ≤100g**（胸前悬挂的舒适上限；跑动不甩打）。屏幕定 2.8" 竖屏嵌背面，顶部单颗 14mm 大键。电池按重量倒推 900-1100mAh。

5. **佩戴方式：挂脖为主 + 腰挂为辅（产品形态的定盘星）**
   佩戴逻辑由使用闭环决定：游历拍照要"抬手即拍"（一秒出机）、手癖要"随时在手里盘"、碰一碰在课间随时发生——设备必须**在身上**，不是在包上。
   - **挂点在顶部正中**（不是角落）：垂挂时"眼睛"朝前——宠物趴在胸口、和孩子看同一个世界；举起即拍，无需摘下（绳长以能抬至眼前为准，环长约 42-46cm）。
   - **屏幕朝内贴胸**：一防磕碰，二成叙事——"它睡在你怀里"；翻转即交互。
   - **胸前 = 行走的展示位**：呼吸眼环在校园里就是广告位与社交发起器，碰一碰变成两个孩子凑近"碰额头"的自然动作。
   - **手癖设计（fidget = 留存的物理形态）**：鹅卵石亲肤哑光壳（"安抚石"手感）、大键的高级段落感、戳一下宠物会回应（已有 poke 交互）——让"无聊时盘它"成为日常肌肉记忆。
   - **安全硬规矩**：挂绳必须用**儿童安全断开扣**（受力即脱开，防勒），符合 GB 6675 绳带要求；附**腰挂/背带夹**转换件（体育课与低龄场景改腰挂）；硅胶缓冲套 + 生活防泼溅。
   - **叙事大礼——"灵宠御守"**：挂在胸前的修仙灵宠 = 电子时代的平安符。爷爷奶奶"给孙子挂平安符"的文化直觉直接接通礼物场景，包装即"开光领养"仪式。

## 三、色彩与配色规范

**策略：中性壳体 × 高饱和点睛 × 五色系可换**（60-30-10 法则）

- **60% 主体**：暖白 `#F5F1E8` / 暖灰 `#E8E4DC`（妈妈端"高级、干净、不像玩具"；也是货架上与噜咔博士小黄机、杂牌糖果色的反差位）
- **30% 辅助**：同色系深一阶的哑光拼色（底盖/按键圈）
- **10% 点睛（高饱和，给孩子）**：发光眼环 + 按键 + 挂绳，颜色随所购色系

**五色系（对应五行元素，同时覆盖性别与年龄谱系）：**

| 色系 | 点睛色 | 屏内元素 | 审美依据 |
|---|---|---|---|
| 晶蓝 | `#3D8BFF` | 晶系（逻辑） | 7 岁后两性共同首选，男孩尤强——**主推色/默认色** |
| 灵紫 | `#8A63F4` | 声系（表达） | 8-9 岁女孩从粉向紫迁移的落点，兼容男孩（比粉安全） |
| 风绿 | `#2FBF8F` | 风系（观察） | 男孩年龄增长偏好上升色；中性、自然联想 |
| 焰珊瑚 | `#FF6A5B` | 焰系（创造) | 保留暖色活力（偏小年龄/外向孩子），比正红少"警示"联想 |
| 曜金 | `#FFB12E` | 光系（专注） | 幼儿最爱黄的"长大版"——加深降明度成琥珀金，避开幼齿 |
| （回避）| 粉 | — | 男孩强避粉；女孩粉偏好峰值在 5-6 岁已过——**首发不出粉**，需求验证后再补 |

**CMF**：主体哑光亲肤（类肤漆或素材哑光 PC/ABS），点睛件亮泽或半透（灯效透光），眼环灯罩乳白半透。禁止：高光廉价亮塑料、金属拉丝（数码感）、大面积糖果色（杂牌感）。

## 四、防"幼齿化"红线（KGOY 检查清单）

出图/出模前逐条过：
- [ ] 三年级男生愿意把它**挂在脖子上走进教室**吗？（终极检验——比挂书包苛刻一个量级）
- [ ] 无腮红贴片、无双眼笑脸、无婴儿奶嘴形态语言
- [ ] 配色不是粉彩马卡龙全家桶
- [ ] 有一处"力量感"细节（眼环的锐利光弧/境界纹路刻线），呼应修仙世界观
- [ ] 放在噜咔博士旁边：我们像生物，它像玩具相机
