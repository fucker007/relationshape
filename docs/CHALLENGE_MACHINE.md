# AI 最强大脑挑战机 —— 成长挑战系统

一条完整的系统逻辑 + 两个纯 API 客户端（拓麻歌子式设备端 / 双设备调试模拟器）。
**不含语音/硬件**——语音交互交给你现有的设备 + AI 服务器，这里只把"该出什么题、
该更新什么状态、宠物该说什么"算清楚。

> 定位：**挑战是满足爸妈的噱头，陪伴是孩子长期留存的理由。** 本系统是"挑战 + 养成"
> 那一半，与 `relationshape`（陪伴/情商引擎）并列、可共享每孩子状态。

## 跑起来

```bash
python server/app.py --seed --port 8099
#  /device  → 设备端（拓麻歌子式养成，巴掌大小 · 黄金比例 320×518）
#  /        → 双设备调试模拟器（开发自测/后台观察用）
pytest tests/test_growth_engine.py -q        # 31 项行为契约测试
```

## 核心不变量（写进代码与测试的红线）

1. **每天 5 题是唯一数据入口。** 养成/灵材/炼丹/突破/对战全是它的派生，绝不另开任务线。
2. **答错/输了不罚。** 喂养看努力（答错也喂到，质量淡一点）；对战输方仍有星和灵材。
3. **判分防瞎蒙。** 数字整词比对（'19'≠'9'）、紧邻否定不算（'不是黄色'≠答对'黄'）、
   表达题乱敲键盘只得 0.2 且不进家长周报。
4. **不做赌博。** 掉卡确定性、炼丹无失败率、无变率强化；藏卡战力加成封顶。
5. **答案永不下发。** 题面/书目测验都只给题，判分全在服务端。

## 修仙养成体系（宠物 = 境界本体）

```
宠物每日渴求（修行缺什么 → 今天 5 题的域配比，主渴求域 +1 题）
   ↓
答 5 题 = 喂 5 口灵材（理科·晶尘 / 文科·韵露 / 博物·灵芝）
   ├─ 能力评估（五维「修为」：蒙童→小天才→…→一代宗师，滚动正确率喂暴击）
   ├─ 智慧星 / 卡牌（藏品卡·修为卡·坚持卡·对战卡·境界卡）/ 家长周报高光
   └─ 喂饱一天 → 境界推进
境界：蛋(7天破壳,物种=喂养亲和最高的域) → 幼年期 → 筑基期 → 结丹期 → 元婴期
   突破门 = 修行天数 × 丹药 × 法器 × 全面修为（五能力最低值，逼均衡）
丹药：灵材按跨域配方炼成（筑基丹/结元丹/化婴丹）；一炉丹只为眼前这道门，不许囤积
法器：书阁读真文（西游记/龟兔赛跑/曹冲称象/小水滴/悯农）→ 回来说说（2 题小测）→ 解锁
云游：3 天不来，蛋沉睡/宠云游——答一题即唤回（期待向，永不指责）；家长端可一键召回
```

## 对战（碰一碰）

- **战力并入境界：同境界才能切磋**（蛋不可战）；境界即层级，天然不碾压。
- 同境界内战力仍悬殊（≥2.2×）→ **友谊赛**：同血池、点到为止、输了不掉成长。
- 数值双轨：**努力→HP 体魄**（坚持/活跃/喂养总量，地板），**正确率→暴击**（锋芒，封顶）；
  逻辑→攻击、专注→速度、表达→绝招、创造→变招；战力 = 拆解之和（家长可见因果）。
- 服务端跑确定性回合制 → `battle_log`，客户端只播动画（HP 条/暴击飘字/KO）。

## 分层（服务端/客户端完全分离）

| 层 | 目录 | 职责 | 依赖 |
| --- | --- | --- | --- |
| 引擎 | `growth/` | 判分/能力/喂养/境界/炼丹/书阁/对战/报告 | 纯标准库，headless，时间注入可回放 |
| 传输 | `server/` | 引擎方法 → JSON + 静态托管 + 模拟时钟 | 仅 `http.server` |
| 客户端 | `device/` `client/` | 渲染状态、发动作、播动画 | 原生 JS，零业务逻辑 |

`growth/` 模块地图：`types`(数据语言) `bank_data`(70 题种子题库) `challenges`(渴求配比抽题+判分)
`abilities`(修为+滚动正确率) `cultivation`(宠物之魂：境界/灵材/丹药/渴求/云游) `books`(书阁)
`cards`(卡牌目录+确定性掉落) `battle`(战斗属性+回合模拟) `rewards`(智慧星) `report`(家长周报)
`state`(每孩子文档) `persistence`(原子 JSON) `engine`(编排唯一入口)。

## API（你的硬件 client 发同样的 JSON 即可接入）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/children` | 所有孩子概览（境界/战力/连续/卡牌） |
| POST | `/api/children` | 新建 `{name, age, grade}` |
| GET | `/api/child/{id}/home` | 主屏全量：宠物(境界/灵材/渴求/突破清单/云游态)/能力/战力/今日 5 题/事件 |
| POST | `/api/child/{id}/answer` | `{cid, answer}` → 判分+讲解引申+喂养+卡牌+破壳/突破事件 |
| POST | `/api/battle` | `{a, b}` → 同境界校验 + battle_log + 奖励 |
| POST | `/api/child/{id}/alchemy` | `{pill}` → 开炉炼丹（可能连锁触发突破） |
| GET | `/api/child/{id}/books` | 书阁（正文+题面，无答案） |
| POST | `/api/child/{id}/book` | `{bid, answers[]}` → 过测解锁法器 |
| POST | `/api/child/{id}/recall` | 家长召回云游的宠物 |
| GET | `/api/child/{id}/report` | 家长周报（真实滚动正确率/修为/战力拆解/高光片段） |
| GET | `/api/child/{id}/album` | 卡册 |
| GET | `/api/child/{id}/state` | 原始状态文档（后台测试） |
| POST | `/api/clock/advance` `/api/clock/reset` `/api/seed` | 演示时钟 / 演示数据 |

## 和 relationshape 的关系（下一步）

本引擎产出的成长事件（破壳/突破/高光表达/坚持/对战）是天然的记忆素材。喂进
`relationshape` 的记忆层，陪伴者就能说出"上次你那个会飞的恐龙想去火星，我还记得"——
**挑战喂养陪伴的记忆，陪伴让孩子愿意回来挑战**。两个引擎共享每孩子状态、各管一段。
