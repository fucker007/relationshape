# AI 最强大脑挑战机 —— 成长挑战系统

一条完整的系统逻辑 + 一个纯客户端模拟器（含两台设备 / 碰一碰对战）。**不含语音/硬件**——
语音交互交给你现有的设备 + AI 服务器，这里只把"该说什么、该更新什么状态"算清楚。

> 定位回顾：**挑战是满足爸妈的噱头，陪伴是孩子长期留存的理由。** 本系统是"挑战 + 养成"那一半，
> 与 `relationshape`（陪伴/情商引擎）并列、可共享每孩子状态。

## 跑起来

```bash
python server/app.py --seed --port 8099      # 启动服务端 + 注入两个演示孩子
# 浏览器打开 http://127.0.0.1:8099
pytest tests/test_growth_engine.py -q        # 后台逻辑的契约测试（9 项）
```

界面：左右两台“设备”，各自做每日 5 关、养宠物；中间**碰一碰**让两只宠物按战力开战；
每台设备可切“家长后台”看成长报告；顶栏可**快进一天**，演示连续天数 / 趋势 / 活力衰减。

## 设计上的"完全分离"

| 层 | 目录 | 职责 | 依赖 |
| --- | --- | --- | --- |
| 系统逻辑（引擎） | `growth/` | 能力评估、抽题判分、养成、战力对战、奖励、报告 | 纯标准库，零依赖，headless，可测 |
| 传输 | `server/` | 把引擎方法翻成 JSON API + 托管静态客户端 + 模拟时钟 | 仅 `http.server` |
| 客户端 | `client/` | 渲染状态、发送动作 | 原生 JS，**零业务逻辑** |

- 浏览器**拿不到答案**：`Challenge.public()` 不下发 `answer/explain`，判分只在服务端 → 想作弊也无从下手。
- 客户端只 `fetch`，可换成你的硬件 client：发同样的 JSON 即可接入（API 见下）。
- 引擎时间由参数注入（`now`），可回放、可测试；对战胜负由 `(a,b,day,n)` 哈希派生，确定性。

## 三条产品红线（写进了代码与测试）

1. **答错 / 输了不饿宠物**：宠物成长值、战力只来自**努力**（出勤 / 尝试 / 坚持 / 表达），
   答对只额外多一点点鼓励。答对错只喂"能力评估"。落后的孩子照样能养大宠物。
2. **战力 = 努力，不是充值**——对家长的卖点："别人家游戏充钱变强，这里只有努力能变强。"
3. **碰一碰段位匹配**：段位/战力悬殊自动转**友谊赛**（抹平差距、弱者略占优、输了仍有奖励），
   不把刚买设备的孩子当众打输。

## 系统逻辑总览

```
每日 5 关（脑力热身/逻辑/表达/观察/创造）  ←→  五维能力（专注/逻辑/表达/观察/创造）
        │ 按能力等级×年级自适应抽题（challenges + bank_data）
        ▼
   作答 → 判分（客观题对错；表达/创造只看参与）
        ├─ 能力评估（abilities，诚实：客观看正确率，主观看练习量）
        ├─ 努力奖励（rewards，星 + 成长值，坚持是最大乘数）
        ├─ 喂养宠物（pet，进化 / 装扮 / 活力）
        └─ 徽章 / 高光（进家长报告）
   满 5 关 → 连续天数 + 完成奖励
   碰一碰 → 战力对战（battle）+ 段位匹配 → 双方都有收获
   家长后台 → 成长报告（report，趋势 + 真实片段，而非一张分数表）
```

## API（client 只认 JSON，便于你的硬件接入）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/children` | 所有设备/孩子概览 + 当前模拟日 |
| POST | `/api/children` | 新建 `{name, age, grade}` |
| GET | `/api/child/{id}/home` | 设备主屏：宠物 / 能力 / 战力 / 段位 / 今日 5 关 / 事件 |
| GET | `/api/child/{id}/today` | 仅今日挑战（题面不含答案） |
| POST | `/api/child/{id}/answer` | `{cid, answer}` → 判分 + 讲解引申 + 奖励 + 最新主屏 |
| POST | `/api/battle` | `{a, b}` → 碰一碰对战结果（回合 / 胜负 / 友谊赛 / 奖励） |
| GET | `/api/child/{id}/report` | 家长成长报告 |
| GET | `/api/child/{id}/state` | 原始状态文档（后台测试用） |
| POST | `/api/clock/advance` | `{days}` 快进模拟时钟（演示坚持/趋势） |
| POST | `/api/seed` | 无孩子时注入演示数据 |

接你现有设备：把硬件 client 的"做完一题""碰一碰"事件，转成上面的 `answer` / `battle` 调用即可；
返回的 `home` 里有宠物形态 / 战力 / 段位 / 事件，驱动你的小屏幕与灯效。

## 和 relationshape 的关系（下一步）

本引擎产出的"成长事件"（精彩表达、坚持、里程碑、对战）是天然的记忆素材。把它喂进
`relationshape` 的记忆/奖励，陪伴者就能说出"上次你那个会飞的恐龙想去火星，我还记得"——
**挑战喂养陪伴的记忆，陪伴让孩子愿意回来挑战**。两个引擎共享每孩子状态、各管一段，是后续的融合点。
