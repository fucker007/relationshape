# 🚧 Phase 2：事件中心建模（结构升级）

👉 从“碎片记忆” → “事件模型”

---

## 🎯 目标

统一核心结构：

> 人 + 时间 + 地点 + 事件 + 参与者 + 情绪

---

## ✅ 新数据结构

```json
{
  "event": {
    "who": "小明",
    "when": "2026-03-01",
    "where": "公园",
    "what": "和明明一起玩",
    "participants": ["明明"],
    "emotion": "开心"
  }
}
```

---

## 🧪 测试要求

### 1. 事件完整率

* 是否抽取完整（who/what/when）

要求 ≥ 90%

---

### 2. 多人事件

```text
我和明明、东东一起去公园
```

必须识别：

* 3人关系

---

### 3. 时间模糊测试

```text
昨天 / 上周 / 很久以前
```

要求：

* 标准化正确率 ≥ 85%

---

### ✅ 通过标准

```
✔ 事件结构完整率 ≥ 90%
✔ 多人解析正确率 ≥ 90%
```
