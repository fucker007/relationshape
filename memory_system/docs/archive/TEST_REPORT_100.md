## 错误分析与修复

### 已知问题（非致命）

1. **AttributeError: 'str' object has no attribute 'get'** (出现 ~15 次)
   - 位置：属性处理中
   - 原因：某些属性值被处理为字符串而非字典
   - 影响：后台错误，不影响对话流程
   - 状态：✅ **已修复**
   - 修复方案：在 `profile_updater.py` 中添加类型检查，将字符串 JSON 解析为对象

2. **UndefinedColumnError: column "updated_at" of relation "events"** (出现 ~5 次)
   - 位置：事件更新时
   - 原因：数据库表结构缺少 `updated_at` 列
   - 影响：后台错误，不影响对话流程
   - 状态：✅ **已修复**
   - 修复方案：
     - 在 `pg_store.py` 的 CREATE TABLE 语句中添加 `updated_at TIMESTAMPTZ DEFAULT NOW()` 列
     - 创建迁移脚本 `migrations/001_add_updated_at_to_events.sql` 更新现有数据库
     - 运行 `python migrations/run.py` 应用迁移

3. **JSON 解析失败** (出现 ~2 次)
   - 原因：LLM 返回格式不完整
   - 影响：极少数情况，不影响整体
   - 状态：可接受
