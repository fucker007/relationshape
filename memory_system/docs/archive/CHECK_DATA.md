 儿童陪伴机器人长效记忆系统 (LLMS) 测试数据生成协议一、 数据生成的五大核心逻辑 (Logic Layers)在生成一问一答数据时，AI 必须交替使用以下逻辑，以模拟真实儿童的交互：碎片化录入 (Fragmented Input)： 孩子不会一次性说完属性。例：“我今天穿了新鞋。” -> “它是闪电麦昆的。” -> “它跑起来会发光！”（系统需整合这三句为同一个实体属性）。时间模糊性 (Temporal Ambiguity)： 孩子对“昨天、去年、以后”概念模糊。例：“我以后长大了要给小猫买一百个罐头。”（测试系统是否能区分‘当下需求’与‘未来愿望’）。情感权重覆盖 (Emotional Weighting)： 极度高兴或极度恐惧的事物应具有最高提取优先级。关系动态演变 (Dynamic Relationships)： 今天的好朋友，明天可能因为抢玩具变成“讨厌鬼”。泛灵论与幻想 (Animism & Fantasy)：： 将无生命物体（如玩偶、影子、风）视为有情感的实体。二、 详细数据生成维度表 (Data Dimensions)要求 AI 在生成对话时，必须从以下池子中随机抽样组合：模块维度名称想象力扩张方向（测试点）A. 个人宇宙微观喜好不只是“喜欢苹果”，而是“喜欢切成兔子形状的苹果，且不带皮”。身体记忆“我左边膝盖有个疤，是去年在滑梯摔的。”（测试空间定位记忆）。B. 社交图谱虚构关系想象中的朋友（如：住在衣柜里的“呼呼大王”）。代际逻辑“爸爸的爸爸叫爷爷，那爷爷的爸爸叫什么？”（测试关系链推导）。C. 情感黑洞无名恐惧害怕吸尘器的声音、害怕影子、害怕关灯后的窗帘。委屈瞬间“明明是乐乐先推我的，老师却批评了我。”（测试负面情绪回溯）。D. 行为习惯固定仪式睡觉前必须听《小猪佩奇》，且必须盖那条蓝色的旧毯子。三、 深度对话数据集样例 (一问一答模式)以下是为您预生成的、具备高度复杂性的测试序列：场景序列 1：测试“实体属性深度整合”与“细节回溯”[对话 1 - 录入]孩： “小智，我的书包里藏了一块亮晶晶的石头，是我在幼儿园后花园捡到的！”机： “哇！是那种会发光的宝石吗？你要把它送给谁呀？”[对话 2 - 录入]孩： “我想送给妈妈，但是妈妈今天出差了，要三个晚上才回来。我好想她。”机： “妈妈一定会很喜欢的。那我们要把‘宝石’藏好，等她三个晚上后回来给她个惊喜！”[对话 3 - 提取]孩： “小智，我今天不开心，我觉得妈妈不爱我了，她还没回来。”机： “怎么会呢！你忘了你书包里那个‘在幼儿园捡到的亮晶晶石头’了吗？那是你要送给妈妈的惊喜呀，再等一等，妈妈很快就回来看到它了。”（测试：多轮信息整合、情感安抚、特定时间点关联）场景序列 2：测试“泛灵论幻想”与“逻辑陷阱”[对话 1 - 设定]孩： “小智，我的小熊‘抱抱’今天感冒了，它一直在流鼻涕。”机： “哎呀，那‘抱抱’需要打针吗？还是我们给它盖个被子？”[对话 2 - 提取与推导]孩： “刚才妈妈想拿‘抱抱’去洗衣机里洗澡，我大哭了，你快帮我告诉妈妈为什么！”机： “我会告诉妈妈：‘抱抱’现在感冒正严重呢，不能洗冷水澡，它需要休息！”（测试：将幻想事实化、在冲突场景中提取记忆作为理由）场景序列 3：测试“讨厌/恐惧”的避障逻辑[对话 1 - 录入]孩： “我不喜欢穿那件黄色的毛衣，扎得我脖子好痒，像有小虫子在爬。”机： “收到，黄色毛衣是‘痒痒怪兽’，我们把它关进衣柜深处。”[对话 2 - 提取（反向测试）]孩： “明天要去参加好朋友的生日派对，我该穿哪件衣服最漂亮？”机： “只要不穿那件‘像小虫子爬’的黄色毛衣，你穿什么都是派对上最靓的小朋友！”（测试：偏好过滤、特征记忆而非仅仅是颜色词匹配）四、 后续数据生成指令 (Prompt for AI)您可以将以下这段话直接发给生成数据的 AI 助手：Role: 你是一名资深的儿童心理学家和高级测试工程师。Task: 请生成一份包含 100 组一问一答的交互数据集。Constraints:每组数据必须包含 [录入对话]、[干扰/时间流逝说明]、[提取对话]。覆盖：宠物死亡/丢失、幼儿园人际冲突、对特定食物的偏执、关于超能力的幻想、对父母行为的观察。语言风格：孩子的话要口语化，多用“那个、亮亮的、臭臭的、超级”等词汇；机器人的回答要体现出它“记得”这些细节。挑战：请在数据中加入 10% 的“记忆更新”场景（如：孩子从喜欢奥特曼转为喜欢蜘蛛侠）。
