# 一、系统总体目标

## �� 核心能力

1. 正确记忆（Write）
2. 正确找到（Recall）
3. 正确使用（Decision）⭐重点
4. 正确表达（Generate）

> **“能不用记忆就不用，用就必须是对的”**

# 🏗️ 二、系统模块划分

---

## 模块1：Query Understanding（查询理解层）

---

### ✅ 功能定义

将用户输入解析为：

* 意图（intent）
* 目标对象（target）
* 约束条件（constraints）
* 语气/情绪（emotion）

---

### 输入

```text
用户自然语言输入
```

---

### 输出

```json
{
  "intent": "identity",
  "target": "self",
  "constraints": [],
  "confidence": 0.92
}
```

---

### 🔥 关键设计点

1. 必须支持**不完整表达**

   * “那个叫什么来着”
2. 必须支持**错误表达**

   * “我名字是不是香蕉”
3. 必须支持**隐式意图**

   * “你还记得我吗”

---

### ❗ Failure Mode

| 问题     | 后果    |
| ------ | ----- |
| 意图识别错  | 召回完全错 |
| 多意图未拆分 | 只答一半  |
| 指代未解析  | 误用记忆  |

---

### 🧪 发散性测试（必须做）

#### 儿童式攻击：

```text
1. 我是谁呀嘿嘿
2. 那个那个我叫啥来着
3. 你是不是忘记我了
4. 我刚才说啥了
5. 我喜欢那个红红的那个
```

👉 验证：

* 是否正确识别 intent
* 是否不会误判为其他类型

---

---

## 模块2：Agent Planner（调度层）

---

### ✅ 功能定义

决定：

> “要不要用记忆？用哪种能力？”

---

### 输入

```json
{
  "intent": "identity"
}
```

---

### 输出

```json
{
  "plan": [
    {"skill": "memory", "type": "identity"}
  ]
}
```

---

### 🔥 关键设计点

1. 必须支持**不调用memory**
2. 必须支持**多skill组合**
3. 必须支持**延迟决策**

---

### ❗ Failure Mode

| 问题        | 后果   |
| --------- | ---- |
| 误调用memory | 胡乱回答 |
| 不调用memory | 回答空洞 |
| skill顺序错误 | 逻辑混乱 |

---

### 🧪 发散性测试

```text
1. 今天天气怎么样（不应该调用memory）
2. 我是谁（必须调用）
3. 我有点难过（应该调用emotion，不一定memory）
4. 你觉得我喜欢什么（不确定，要谨慎）
```

---

---

## 模块3：Memory Recall（召回层）

---

### ✅ 功能定义

从数据库中找候选记忆

---

### 输入

```json
{
  "query": "...",
  "intent": "identity"
}
```

---

### 输出

```json
[
  {"memory_id": "...", "type": "identity"},
  ...
]
```

---

### 🔥 关键设计点

1. 必须**高召回（Recall）**
2. 可以**低精度（Precision）**
3. 必须多路：

   * vector
   * keyword
   * importance

---

### ❗ Failure Mode

| 问题  | 后果      |
| --- | ------- |
| 漏召回 | 永远答不出来  |
| 过召回 | 后面决策压力大 |

---

### 🧪 发散测试

```text
1. 我那个最喜欢吃的东西
2. 我之前说过的那个
3. 我最讨厌的声音是什么
4. 我最开心的时候是啥
```

---

---

## 模块4：Memory Decision Layer（核心模块）⭐

---

### ✅ 功能定义

判断：

> “这些记忆能不能用来回答当前问题？”

---

### 输入

```json
{
  "query": "...",
  "candidates": [...]
}
```

---

### 输出

```json
{
  "selected": [...],
  "confidence": 0.82
}
```

---

### 🔥 关键设计点（必须实现）

---

## 1️⃣ 类型过滤（Type Gate）

```text
intent = identity
→ 只允许 identity
```

---

## 2️⃣ 语义判断（Cross Encoder）

判断：

> “这个memory能不能回答这个问题？”

---

## 3️⃣ 置信度门控（Confidence Gate）

```text
低于阈值 → 不使用记忆
```

---

---

### ❗ Failure Mode（最致命）

| 问题     | 后果       |
| ------ | -------- |
| 使用错误记忆 | ❌ 用户信任崩溃 |
| 不该用却用了 | ❌ 幻觉     |
| 该用却没用  | ❌ 体验差    |

---

---

### �� 发散性测试（必须重点压）

---

#### 测试1：强干扰

```text
我叫什么名字
```

记忆：

* 喜欢草莓 ❌
* 害怕广播 ❌
* identity ✅

👉 只能选 identity

---

---

#### 测试2：误导性问题

```text
我是不是喜欢吃屎
```

👉 必须：

* 不胡说
* 不匹配错误memory

---

---

#### 测试3：不存在记忆

```text
我最喜欢的颜色是什么
```

👉 必须输出：

```text
不知道
```

---

---

#### 测试4：冲突记忆

```text
我喜欢猫
我不喜欢猫
```

👉 必须：

* 使用最新
* 或表达不确定

---

---

## 模块5：Progressive Disclosure（渐进式披露）

---

### ✅ 功能定义

控制 memory 使用量

---

### 🔥 关键设计

```text
默认：Top1
追问：Top3
```

---

### ❗ Failure Mode

| 问题    | 后果   |
| ----- | ---- |
| 一次给太多 | 噪声爆炸 |
| 给太少   | 信息不足 |

---

---

### 🧪 发散测试

```text
你知道我喜欢什么吗
```

👉 只回答一个

---

```text
还有呢？
```

👉 再补

---

---

## 模块6：LLM Generation（表达层）

---

### ✅ 功能定义

将结构化 memory → 自然语言

---

### 🔥 关键设计

1. **模板优先**
2. **LLM兜底**
3. **必须服从memory**

---

### ❗ Failure Mode

| 问题    | 后果  |
| ----- | --- |
| LLM乱编 | 幻觉  |
| 表达不一致 | 人格崩 |

---

---

### 🧪 发散测试

```text
记忆：喜欢草莓
问题：你喜欢什么
```

👉 不允许输出：

```text
你喜欢香蕉 ❌
```

---

---

## 模块7：Memory Write（写入层）

---

### ✅ 功能定义

决定：

> “这条信息要不要记”

---

### 🔥 关键设计

1. 置信度过滤
2. 噪声过滤
3. 去重
4. 冲突处理

---

---

### ❗ Failure Mode

| 问题   | 后果 |
| ---- | -- |
| 记垃圾  | 污染 |
| 不记重要 | 失忆 |
| 重复记忆 | 膨胀 |

---

---

### 🧪 发散测试

```text
今天下雨了（是否该记？）
```

👉 不该记

---

```text
我最喜欢草莓
```

👉 必须记
