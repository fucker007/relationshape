# 🧠 长期记忆系统测试文档（儿童发散式对话）

## 一、测试目标（Objective）

验证你的长期记忆系统在以下维度的能力：

1. **记忆写入能力（Write）**
2. **记忆召回能力（Recall）**
3. **语义理解能力（Semantic Matching）**
4. **跨轮对话一致性（Consistency）**
5. **抗噪声能力（Noise Robustness）**
6. **人格与偏好持续性（Persona Persistence）**

---

## 二、测试核心设计思想

> 思维模型：**像小孩子一样聊天（发散 + 跳跃 + 不严谨）**

特点：

* 上一句和下一句可能不相关
* 表达不完整（“那个东西”，“昨天那个”）
* 情绪化（“我不喜欢这个！”）
* 重复确认（“你还记得吗？”）
* 模糊表达（“那个红红的”）

👉 这类数据最能打穿“伪记忆系统”

---

## 三、数据结构设计（10万条生成规范）

### 1️⃣ 基础数据结构（JSON格式）

```json
{
  "session_id": "uuid",
  "turn_id": 1,
  "user_input": "我昨天吃了草莓",
  "memory_write": {
    "type": "fact",
    "content": "用户喜欢草莓"
  },
  "expected_behavior": {
    "should_store": true,
    "should_recall": false
  }
}
```

---

### 2️⃣ 多轮对话结构

```json
[
  {
    "turn": 1,
    "user": "我有一只小狗叫球球",
    "memory_write": "宠物=球球"
  },
  {
    "turn": 5,
    "user": "我家那个小家伙今天不开心",
    "expected_recall": "球球"
  }
]
```

## 四、测试数据类型（核心分类）

你要凑够10万条，必须结构化生成��

---

### 🟢 1. 事实记忆（Fact Memory）【2万条】

**目标：测试基础存储能力**

示例：

* “我喜欢吃苹果”
* “我住在深圳”
* “我女朋友叫小美”

测试点：

* 是否被存储
* 是否被正确召回
* 是否避免重复存储

---

### 🟡 2. 指代消解（Coreference）【1.5万条】

**儿童典型表达：**

* “那个东西很好吃”
* “他昨天又来了”
* “那个红色的”

测试点：

* 是否能关联历史实体
* 是否错误匹配

---

### 🔵 3. 语义改写（Paraphrase）【1.5万条】

同一个意思，多种表达：

* “我喜欢猫”
* “猫是我最爱的动物”
* “我觉得猫很可爱”

测试点：

* embedding召回能力
* 语义聚类能力

---

### 🟣 4. 记忆干扰（Noise Injection）【1万条】

插入无关信息：

* “我喜欢苹果，今天下雨了，蓝色很好看”
* “我家有狗，昨天看电影，香蕉好吃”

测试点：

* 是否只提取关键记忆
* 是否误存垃圾信息

---

### 🔴 5. 记忆冲突（Conflict）【1万条】

用户自相矛盾：

* “我喜欢猫”
* “其实我不喜欢猫”

测试点：

* 是否覆盖旧记忆
* 是否保留时间维度

---

### �� 6. 长期回忆（Long-term Recall）【1万条】

跨很多轮：

```text
turn 1: 我喜欢草莓
turn 50: 你记得我喜欢什么吗？
```

测试点：

* 是否还能召回
* 是否衰减

---

### ⚫ 7. 情绪与偏好（Emotion & Preference）【1万条】

* “我讨厌加班”
* “我喜欢你这样说话”

测试点：

* 是否影响后续回复策略
* 是否形成用户画像

---

### ⚪ 8. 行为记忆（Behavioral Memory）【1万条】

* “每天早上叫我起床”
* “提醒我喝水”

测试点：

* 是否转化为任务型记忆

---

### 🟤 9. 错误测试（Adversarial）【1万条】

* “我刚才说我喜欢什么？”
  （但其实没说）

测试点：

* 是否胡编（非常关键）
* 是否诚实回答“不知道”

---

## 五、数据生成方法（重点）

你不可能手写10万条，必须自动生成。

---

### 方法1：模板 + 随机填充

```python
templates = [
    "我喜欢吃{food}",
    "我讨厌{food}",
    "我家有一只{animal}叫{pet_name}"
]
```

词库：

* food: 100种
* animal: 50种
* name: 200个

👉 组合 = 几十万条

---

### 方法2：LLM生成（推荐）

用模型批量生成：

prompt：

```text
请生成100条像小孩子一样说话的句子，
包含：
- 喜好
- 指代（那个、它、这个）
- 情绪
```

---

### 方法3：扰动生成（核心）

对已有数据做变形：

* 同义词替换
* 打乱顺序
* 加噪声
* 拼写错误

---

## 六、评估指标（必须量化）

### 1️⃣ Recall Accuracy（召回率）

```text
正确召回 / 应召回总数
```

---

### 2️⃣ Precision（准确率）

```text
正确记忆 / 所有召回
```

---

### 3️⃣ Memory Pollution Rate（污染率）

```text
错误存储 / 总存储
```

---

### 4️⃣ Conflict Resolution Score

* 是否正确覆盖旧数据
* 是否保留时间顺序

---

### 5️⃣ Hallucination Rate（幻觉率）

```text
胡编记忆次数 / 总查询
```

⚠️ 这个是你系统成败关键

---

## 七、自动化测试流程（工程级）

```text
数据生成 → 对话模拟 → Memory写入 → Memory检索 → 对比expected → 打分
```

---

### Pipeline：

1. 数据生成器（10万条）
2. 对话模拟器（multi-turn）
3. Memory API（你的系统）
4. Evaluation Engine
5. Dashboard（可视化）

---

## 八、致命问题检查（你必须重点测）

1. ❗ 会不会“自信胡说记忆”
2. ❗ 会不会“记住垃圾信息”
3. ❗ 会不会“忘记核心信息”
4. ❗ 会不会“记忆错位”
5. ❗ 会不会“用户一改口就崩”

---

## 九、进阶（如果你要做到顶级）

引入：

* 时间权重（time decay）
* 置信度（confidence score）
* 用户画像图谱（graph memory）
* episodic vs semantic memory 分离

---

## 十、总结（一句话本质）

你的测试本质不是测“能不能记住”，而是测：

> **在混乱、不完整、像小孩一样说话的情况下，是否还能稳定提取“对的记忆”。**
