# 🚧 Phase 1：记忆使用决策层（你当前最大问题）

👉 **这是必须先做的，否则系统是“错的”**

---

## 🎯 目标

解决：

> ❗ “召回到了 ≠ 应该用”

---

## ✅ 新增模块

### 1️⃣ Memory Relevance Judge（核心）

输入：

* query
* memory

输出：

* relevance_score
* use / skip

---

### 2️⃣ Intent 分类器

```text
identity / preference / emotion / relationship / general
```

---

### 3️⃣ Type Gate（强约束）

```text
问名字 → 只能 identity
问吃什么 → preference
```

---

## 🧪 测试设计（关键）

### 测试集（必须生成 10万条）

#### 类别：

1. 正确匹配
2. 语义相似但错误
3. 完全无关
4. 对抗样本（干扰）

---

### 指标

| 指标               | 要求    |
| ---------------- | ----- |
| Precision（使用正确率） | ≥ 95% |
| Recall（不漏用）      | ≥ 90% |
| 错误使用率            | ≤ 5%  |

---

### ❗关键测试样例

```text
Query：你认识我吗
Memory：喜欢草莓 ❌（必须过滤）
Memory：名字是小明 ✅
```

---

### ✅ 通过标准

```
✔ 错误记忆使用率 ≤ 5%
✔ identity 类准确率 ≥ 98%
```
