---

## 🎯 目标

> 👉 推理能力（为什么）
> 👉 行为驱动（我要什么）

```text
考试失败 → 难过 → 不想学习
```

```json
{
```

## 🧪 测试

### 因果测试

输入：

```text
考试没考好，我很难过
```

* 因果链

---

### 目标测试

输入：

```text
我想变得更厉害
```

必须生成：

* goal

---

### 指标

```
✔ 因果识别 ≥ 85%
✔ 目标识别 ≥ 90%
```

# 🧠 五、开发铁律（非常重要）

---

## ❗原则 1：每阶段必须“可验证”

不能靠感觉：

> 必须有指标 + 自动测试

---

## ❗原则 2：先解决“错”，再提升“强”

顺序必须：

```
正确性 → 结构 → 智能
```

---

## ❗原则 3：禁止跨阶段开发

例如：

* 没做 relevance → 不准做 goal system
